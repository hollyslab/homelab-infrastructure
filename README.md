## Overview
This repository documents my home lab environment built for learning and demonstrating IT infrastructure skills. It includes a Windows Server Active Directory setup, virtual machines, and supporting scripts and documentation.

## Lab Goals
- Build and manage a Windows Server Active Directory (AD) environment
- Deploy and configure virtual machines for different roles
- Practice system administration, networking, and security concepts
- Document infrastructure for professional development and job readiness

## Environment Setup
- Host: VMWare
- Domain Controller: Windows Server Active Directory
- Client VMs: Windows 11 (Staging Environment), Windows Server 2025 (Staging Environment )
- Networking: NAT

## Repository Structure
- `/documentation` – Setup guides, notes, diagrams
- `/scripts` – PowerShell or automation scripts
- `/future plans` – Future ideas or upgrades for the home lab
- `/diagrams` – Network architecture visuals

## Skills Demonstrated
- Active Directory administration
- User and group management
- VM deployment and configuration
- Basic network design and segmentation
- PowerShell scripting and automation
